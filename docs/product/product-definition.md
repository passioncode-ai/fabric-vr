## 1. Что это

**Твой VR Notes.** Приложение для Meta Quest, ядро которого — **заметки**: текст, голос, наброски
от руки, схемы, файлы — организованные как база знаний (теги, поиск, бэклинки, ежедневная
страница), принадлежащие пользователю и синхронизированные между гарнитурой, компьютером и
телефоном. Вокруг ядра — **инструменты**, которые работают не только внутри заметок, а во всей
работе в гарнитуре: голосовой ввод и speech-to-text в любое поле, хранилище и передача файлов,
единый буфер обмена. И **AI-агент, с которым разговариваешь**: он знает твои заметки и умеет
делать работу на твоём компьютере.

Формула: **Notion для VR + инструменты (голос, STT, storage, файлы, буфер) + агент.**

## 2. Чем это НЕ является

- **Не десктоп и не конкурент десктопам.** Экран компьютера в VR показывают Meta Virtual
  Display (встроен в Horizon OS, бесплатен), Virtual Desktop, Immersed и те, что появятся.
  Мы не рендерим десктоп никогда. Мы — инфраструктура рядом с любым из них.
- **Не клиент звонков и не стример.** Звонки идут в Zoom/Meet/Teams на компьютере; мы даём
  инструменты (микрофон, заметки к встрече) — позже, как инструмент, не как ядро.
- **Не «ещё один холст».** Все VR-инструменты (ShapesXR, Figmin, Softspace, Horizon Dock) —
  холсты без базы знаний. Наш холст — один из видов заметки внутри базы знаний.

### 3.1 Ядро — заметки

- Виды: текстовая, голосовая (аудио + транскрипт + структура), набросок/схема (штрихи +
  распознанный текст + сгенерированная Mermaid/Excalidraw), файл/вложение, веб-клип.
- Организация: теги, полнотекстовый поиск, бэклинки, ежедневная страница, сущности (люди,
  проекты) — общие с памятью агента. **База знаний с первого дня**, не холст с поиском потом.
- Хранение: **vault — папка пользователя** (Markdown для текста, Excalidraw-JSON для схем,
  InkML/точки для сырых штрихов, аудио как вложение), совместимая с Obsidian; CRDT
  (Automerge/Loro) для offline-first синка между Quest, компьютером и телефоном; опциональный
  E2E-облачный синк; one-way push в Notion API.
- Пространство: заметку можно закрепить к столу/стене (Spatial Anchors/MRUK) в immersive-режиме,
  но плоский список всегда доступен — дрейф якорей не теряет заметки.

### 3.2 Инструменты (везде, не только в заметках)

| Инструмент | Что делает | Где работает |
|---|---|---|
| Голос / PTT | кнопка контроллера, жест, кнопка панели; hands-free позже | в наших панелях; на компьютере — горячая клавиша/компаньон |
| Speech-to-text | диктовка RU/EN в **любое поле** на компьютере (Accessibility → paste → Unicode), личный словарь и стиль по приложению | компьютер через компаньон — независимо от того, какой десктоп показывает экран |
| Storage и файлы | vault + передача файлов гарнитура ↔ ПК ↔ телефон (ссылка + ленивая загрузка) | все три устройства |
| Буфер обмена | текст/ссылки eager, изображения/файлы лениво; хост — хаб; флаги конфиденциальности на захвате | Quest (наша панель/IME), Mac/Win, iOS (Share Sheet/Shortcuts), Android (IME) |
| Быстрые ops | «отправь…», «поставь таймер», «что дальше», уведомления телефона в VR | панель + компаньоны |

### 3.3 Агент

- Живёт на компьютере (Claude Agent SDK + computer use, MCP-сервер хоста); Fabric Provider по
  `fabric-agent-contract`.
- Два режима разговора: **о заметках** («что я решил на прошлой встрече с дизайнером?», «собери
  дайджест за неделю», «свяжи эти три заметки») и **о работе на компьютере** («открой…,
  найди…, перешли…») с режимами надзора Manual/Auto/Skip, нарративом статуса, подтверждением
  необратимого и STOP.
- Память = сам vault (semantic) + experiential-записи об исправлениях и привычках (Fabric
  Memory Kernel). Заметки — **system of record**, агент — **system of engagement**.

### 3.4 Поверхности и десктоп-агностичность

- **Quest-приложение — 2D-панель в оболочке Horizon OS** (Android Activity / Compose), живёт
  рядом с экранами Meta Virtual Display, браузером и другими панелями (оболочка даёт до 3
  докованных + плавающие панели). По желанию — **immersive «Space»** с той же панелью и
  пространственными заметками: официальный паттерн **Spatial SDK HybridSample** («begin with
  a standard Android-based 2D panel experience and switch between an immersive experience that
  hosts the same panel») — github.com/meta-quest/Meta-Spatial-SDK-Samples, прочитано 2026-09-19.
- **Компьютерная часть работает с любым стримером**: диктовка, буфер, файлы, агент — на хосте;
  какое приложение показывает экран в VR — Meta Virtual Display, Virtual Desktop, Immersed —
  нам безразлично.
- Честное ограничение: когда на переднем плане **immersive**-десктоп (Virtual Desktop,
  Immersed), панели сторонних приложений скрыты — наши инструменты в этот момент доступны через
  компьютер (горячая клавиша PTT, компаньон на телефоне), а панель — после выхода в оболочку.
  С Meta Virtual Display (панели оболочки) мы живём одновременно. **Проверить на устройстве**
  (гарнитура была offline при исследовании).

## 4. Накапливающаяся ценность

Каждая заметка, диктовка, исправление агента и перенос между устройствами пополняет vault и
память: словарь и стиль (диктовка точнее), сущности и связи (поиск и дайджесты умнее),
политика агента под твою машину (меньше шагов и вопросов). Всё принадлежит пользователю
(папка + MCP-ресурс, экспорт, импорт памяти из других ассистентов), обрабатывается local-first,
облако — по флагу. Это дифференциация против holст-приложений (ничего не накапливают) и против
Meta (Meta AI на Quest не знает твоих заметок и твоего компьютера).

| Фаза | Результат |

| **1. Notes Core** | текст + голосовые заметки + наброски, теги/поиск/бэклинки/daily, Obsidian-совместимый vault. **v1 работает на одном Quest и хранит данные на гарнитуре**: без аккаунта, без синка, без второго пользователя (`DEC-0023`, см. *The second headset* ниже); заметки уходят с гарнитуры только архивом-экспортом |
| **2. Voice tools** | PTT, диктовка в любое поле на компьютере, личный словарь, быстрые ops |
| **3. Clipboard + Storage + файлы** | хаб на хосте, **vault на Mac и синк Quest ↔ Mac** (перенесено из фазы 1 решением `DEC-0023`), Quest, iOS Share Sheet, Android IME, передача файлов |
| **4. Agent** | разговор о заметках + работа на компьютере с надзором, Dispatch с телефона, память |
| **5. Space** | immersive-режим: заметки на столе и стенах, якоря + список |
| **6. Calls как инструмент** | виртуальный микрофон, заметки к встрече, память встреч без бота; аватар — по результатам теста |
| **7. Windows, телефоны, Store** | паритет, листинг с подпиской, VRC, privacy labels |

**What exists today (2026-09-23).** The APK links four modules — `:core-common`, `:core-notes`,
`:feature-vault` and `:feature-stt` (`app/build.gradle.kts`). `:feature-assistant` is in the tree
and in `settings.gradle.kts` but is not linked (`DEC-0020`). There is no code for the cross-device
clipboard (`B-031`), the Notion push, sketches or agents; the clipboard that exists is the
headset's own system clipboard, which a finished dictation is copied to (`DEC-0012`). What ships is
roughly phase 1's capture half on the Quest only: text and voice notes, tags, search, the daily
note, the Markdown vault on the headset, and export and restore by archive. `docs/ux/scenarios.md`
is the behaviour-level account.

Каждая фаза: сценарии через `/ux` (`docs/ux/scenarios.md` — источник правды по поведению),
доставка через `/task-pipeline`, тексты через `/copy` после `/brand-init`.

## 6. Упаковка (без изменений по сути)

Бесплатно: заметки локально, диктовка с лимитом, буфер текста. Pro $15–20/мес: агент,
диктовка без лимита, синк устройств и облако, файлы. Team $25–35: общий контекст проекта в
Fabric. Покупка на вебе (одна лицензия Quest + Mac/PC) и дубль подписки в Horizon Store с
триалом; anti-steering по Store Terms — проверить. Имя: «Fabric VR» / «Fabric Notes» —
коллизия с Microsoft Fabric в поиске, trademark-поиск до релиза.

## 7. Проверить до фазы 1

- Сосуществование нашей 2D-панели с экранами Meta Virtual Display и лимит панелей на
  устройстве; поведение при запуске immersive-стримера.
- Природа Horizon Dock (панель или системный оверлей) — есть ли у сторонних приложений
  оверлей над immersive-приложениями (скорее нет).
- Зависимость ML Kit Digital Ink от Play Services на Horizon OS; цены MyScript.
- Правила буфера обмена Horizon OS (AOSP foreground/IME).
- Anti-steering Horizon Store для веб-подписки.

## The second headset

`DEC-0023`: the build on the second person's Quest is a **test copy, not a second user**. v1 gains
no account, no sync and no sharing. Two obligations follow: that person can hand back a diagnosis
without a laptop (`T-011`), and anyone can say which build they are holding (`T-038`).
