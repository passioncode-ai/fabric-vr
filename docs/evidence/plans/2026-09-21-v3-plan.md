## Contracts per module (stage 3, compact)

**G-B.** Contracts, each grounded on a page fetched 2026-09-21 (stage 1):

- `<horizonos:uses-horizonos-sdk horizonos:minSdkVersion="81" horizonos:targetSdkVersion="81"/>`
  as a child of `<manifest>` — Meta, *Requiring Minimum OS Versions*
  (developers.meta.com/horizon/documentation/android-apps/min-os-versions/). Meta's own
  `HybridSample` ships `minSdk = 34` beside a manifest floor of 69 — the same contradiction as
  `B-098`, so it is a sample habit, not a requirement.
- `android:installLocation="auto"` on `<manifest>`; `android.hardware.vr.headtracking` keeps
  `required="false"` (2D launcher class) and gains `android:version="1"` — *Application Manifests
  for Release Builds* (developers.meta.com/horizon/resources/publish-mobile-manifest/).
- `com.oculus.feature.PASSTHROUGH`, `com.oculus.feature.VIRTUAL_KEYBOARD` and
  `oculus.software.overlay_keyboard`, all `required="false"`; `com.oculus.handtracking.version =
  V2.0` — verbatim from `HybridSample/app/src/main/AndroidManifest.xml`.
- `<meta-data android:name="com.oculus.ossplash.background" android:value="passthrough-contextual"/>`
  inside `<application>` — *Passthrough Loading Screen*
  (developers.meta.com/horizon/documentation/native/android/mobile-passthrough-loading-screens/):
  `black` is the default and "not recommended for MR apps".
- Network security config: VRC.Quest.Packaging.4 says only "a valid network security
  configuration"; nothing Meta publishes defines *valid* or rules on a permissive base-config
  (UNVERIFIED at upload). A `domain-config` cannot express RFC1918, so the file ships
  `base-config cleartextTrafficPermitted="true"` with explicit system trust anchors and the
  policy stays where it is (`NetworkPolicy.requireReachable`, `DEC-0005`); the first Developer
  Dashboard upload is what settles it — carry-over row.
- **Transitions.** *Known issues* (spatial-sdk-known-issues, 2026-04-02): "Do not use `finish()`
  to close an activity that has associated panels … Use `panelEntity.destroy()` … Use a helper
  function to launch panel mode in home instead of calling `finish()`." *Spawn and remove 2D
  panels*: "Never use the `finish()` method to terminate an Activity associated with a panel."
  Meta's `HybridSample` (`main`, 0.14.0) nevertheless calls `finish()` after the Home intent and
  omits `finishAndRemoveTask()` on the way in. The recipe this run implements: keep the panel
  entity reference from `onSceneReady`; on leave `panelEntity.destroy()` → the three-intent Home
  launch → **no** `finish()`; the panel activity stays alive on entry (the sample's shape, and the
  one that keeps `NotesViewModel` for the return). The failure behaviour to lock — *the panel is
  reachable after any exit from the Space, and one instance of it exists after five round trips*
  — no JVM test can prove; the row is written `device` and deferred (`DEC-0066`).
- **Microphone silencing** (for G-C/G-E) — *Meta Horizon OS Audio*
  (developers.meta.com/horizon/documentation/android-apps/platform-audio/): "the microphone
  stream isn't closed and is provided empty audio data … `AudioRecordingConfiguration.isClientSilenced()`
  … `AudioManager.isMicrophoneMute()`". Both are checked, per read loop.
- **Haptics** (for G-F) — the only Kotlin API Meta documents is
  `spatial.applyHapticFeedback(hand, amplitude, durationNs, frequency)` on an `AppSystemActivity`
  (*Inputs and controllers*), i.e. Space-only; whether `android.os.Vibrator` reaches Touch
  controllers from a 2D panel is UNVERIFIED. *Haptics: Best practices*: never without a visual or
  audio cue, and always optional. So: an audio cue everywhere, a haptic pulse in the Space only,
  both behind one Settings switch.

**G-C.** `RemoteWhisperClient` form field `language` = hint or `auto`. `ModelDownloader`:
`catch (t: Throwable)` splits — `CancellationException` deletes, any other keeps `.part` and
emits `Failed(reason, resumable = true)`; a 416 deletes `.part` and restarts. Retry lives in
`ModelDownloads` (3 attempts, 1/2/4 s). Remote clients: `suspendCancellableCoroutine` with
`enqueue`, `invokeOnCancellation { call.cancel() }`. `AudioRecorder` registers an
`AudioRecordingCallback`; a silenced client emits `Silenced` on the flow, `VoiceViewModel` maps
it to `VoiceState.Silenced` with its own string.

**G-D.** `VaultZipImporter.import(uri)`: refuses entries outside `notes/`, refuses `..`, refuses
an `id` that is not a UUID; imports through a repository path that preserves timestamps
(`upsertPreservingTimestamps`). `VaultReconciler.reconcile()` runs in `Graph.init` **before**
`FabricApp` composes (a `CompletableDeferred` the UI awaits), and is idempotent: import by id,
never by walk position. `Vault.write`: `tmp` + `fsync` + `renameTo`. FTS v4: `notindexed=noteId`.
`AppError.Network(host)` for `ConnectException`, `SSLException`, `NoRouteToHostException`,
`SocketException`; `UiStateMapper` prints `Storage.op`.

**G-E.** `VoiceViewModel.stopAndTranscribe` launches on `Graph.scope`; the result is handed to a
process-wide `DictationOutbox` (`MutableStateFlow<PendingDictation?>` in `Graph`) that
`NotesViewModel` drains whenever it is alive — so the commit no longer needs a composition.
`UiAction.RETRY` becomes `RETRY_LOAD`, `RETRY_DICTATION`, `RETRY_SPACE`. `BackHandler(enabled =
recording)`. Permission: `permissionInFlight` flag; empty `grantResults` → ignored, not
permanent. Editor `delete()`: `saveJob?.cancel(); saved = true`. Today: a `StatusSlot` above
`LazyColumn` for undo/banners; `justDeleted` cleared on `ON_STOP`.

**G-F.** Strings per REQ-061; `FeedbackCues` (`ToneGenerator` + `Vibrator` where present,
no-op otherwise — the platform answer recorded from the stage-1 fetch); `NOTICE`; Settings →
*Licences*.

**G-G.** `check-docs.sh` §23: the handoff's stated decision/test counts equal the computed ones;
§24: board ids unique. `check-device-gate.sh`: the newest row's result cell must match
`^[0-9]+ (green|red)`; `not run` is refused. Both carry a `selftest.sh` plant.
