## Why this shape

A failed destination must not tell someone their only recording is damaged, and a UUID is
not a locator the headset interface lets them use. Preserve the diagnostic filename in the
error/log, classify only input reads as unreadable, and offer notes-only recovery only for
that recording failure. Keep the existing single audioPath model: the task is to expose and
safely play files already preserved beside a note, not to redesign dictation ownership.

Restoring an archive changes modification clocks, while an in-flight directory result can
outlive the state it describes. Use the preserved filename stamp for earlier recordings and
reject obsolete results, including when the new result is empty. Disable playback while the
microphone is live so another Play press cannot undo the stop at dictation start.
