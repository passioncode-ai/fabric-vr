## Notes for the merge

- **Three findings are really one design gap and should be fixed together:** A-02 (undo loses the audio),
  A-03 (the failure path deletes the audio) and A-04 (a failed save orphans it). The recording has no
  owner across the delete/failure boundaries — `VoiceViewModel.cancel`, `FileVault.remove` and
  `adoptOrKeep` each act on the file with no shared rule. A `.trash` directory plus "only the vault
  deletes vault files" would close all three.
- **A-01, A-07, A-11 are all "state exists, nothing renders it"** (`createNote`, `VoiceState.Allowed`,
  `state.today`/`dayLabel`), and all three date from the `732c92b` "one button, no windows" simplification.
  Whoever holds the UI axis is likely reporting the same holes from the other side; the view-model side is
  intact in each case, so the fix is in the composables plus a scenario update.
- **For the docs/evidence axis:** `docs/modules/feature-stt.md` and `feature-vault.md` each name a test
