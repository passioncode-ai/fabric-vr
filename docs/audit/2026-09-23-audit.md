# Audit — Fabric VR, 2026-09-23

**What was asked** (the operator, in Russian): audit what the last few days produced — the plan,
the tasks done and how done they are, the code, the errors, the documentation — fix every place the
documentation is not true of the tree, and lay out the remaining work by priority.

**Against what:** branch `feat/v1-notes-core` at `88c32fc`, the tip after the 2026-09-22 loop —
202 commits since 2026-09-16 (`git log --since=2026-09-16 --oneline | wc -l`).

**How:** the gates run in full (`bash scripts/check-all.sh`); three independent readings — the code
changed since 2026-09-21, every document against the tree, the UX documents against the screens;
then every High code finding re-read on the main thread before it was written down (`SI-11`: a
subagent's report is not evidence). Findings that were **not** re-read say so in their board row.

## Verdict in five lines

1. **The direction is sound and the notes core is well made** — every gate green on the audited
   tree, 673 JVM tests and a self-test that plants 41 defects; no stub, `TODO` or placeholder in
   `src/main`; zip-slip, the cleartext rule at every hop and the redirect rule all read correct.
2. **But three paths still lose a person's data for good** (`B-237`, `B-238`, `B-239`), all in the
   seams between a Room write, the vault and the outbox — the part the last three runs hardened,
   and the part a JVM test with a fake vault is least able to see.
3. **The documents were wrong in 30 places**, two of them *under a green gate*: §23 counted a KDoc
   line as a test, and the entry document's board numbers were not gated at all. All corrected in
   this change (below).
4. **Nothing has been verified on a headset or by CI since 2026-09-21.** CI's budget is $0
   (`B-195`), 93 of 95 verification rows describe an older tree (`bash scripts/exposure.sh`), and
   every `Human` cell reads `never`.
5. **The product is ~20 % built.** The definition (`DEC-0064`) is notes as a knowledge base +
   AI/agents + a cross-device clipboard; the tree is Phase 1 capture on the Quest alone. The
   clipboard, Notion, agents and every non-Quest surface have no code and no plan.
