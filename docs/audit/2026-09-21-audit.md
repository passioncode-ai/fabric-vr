## 1. Что это за проект

**Цель по репозиторию** (`docs/product/product-definition.md`): «Notion для VR + инструменты
(голос, STT, storage, файлы, буфер) + агент на компьютере»; инфраструктура **рядом** с любым
виртуальным десктопом, «мы не рендерим десктоп никогда» (`:22-24`).

**Что реально построено (v1):** headset-only приложение заметок с диктовкой. Одна кнопка —
запись — whisper.cpp на устройстве (или cloud / свой whisper-server) — заметка + текст в
системный буфер. Room + FTS4 как индекс, Markdown-vault в `filesDir`, экспорт zip в
`Downloads`. Два хоста одного Compose-дерева: 2D-панель (`PanelActivity`) и immersive Space
(`ImmersiveActivity`, Meta Spatial SDK 0.14.0, passthrough).

**Масштаб:** проекту 3 дня (первый коммит 2026-09-19), 138 коммитов; 10 417 строк main-Kotlin
(из них 3 205 — комментарии), 343 строки C++, 371 JVM-тест, 33 инструментальных теста,
29 381 строка Markdown, 63 решения, 183 строки доски.

### Вопрос к оператору, который меняет всё остальное

В записях памяти агента за сегодняшнюю сессию продукт описан иначе: **нативный виртуальный
десктоп к Mac/Windows с голосовым AI-ассистентом, полностью управляющим хостом, и первой фичей —
кнопкой Speech-to-Text в поля удалённого десктопа**.
Это первая концепция, от которой `docs/research/2026-09-19-scope-pivot.md` отказался дважды
(«Do not reinvent the display», затем notes-first). В репозитории этого разворота нет.
Это либо третий поворот скоупа, не записанный в Git, либо старый промпт, попавший в наблюдатель.
**Пока не решено — половина доски может быть работой не над тем продуктом.**

## 2. Как это рендерится

- **Общее.** Один процесс, один `Graph` (`Graph.kt:35`): Room, `FileVault`, `VaultMirror`,
  один `AudioRecorder`, один `LocalWhisperOwner` (мьютекс, один whisper-контекст). Оба хоста
  вызывают `FabricApp` (`ui/FabricApp.kt:32`): тёмная тема, непрозрачный `Surface`,
  `NavHost` на 4 маршрута (`today`, `editor/{id}`, `search`, `settings`). ViewModel'и живут
  в back-stack entry; `SavedStateHandle` и `BackHandler` в приложении нет.
- **Панель.** Обычная `ComponentActivity` + `setContent`; категория
  `com.oculus.intent.category.2D`, 1024×640 dp по умолчанию, минимум 480×560,
  `configChanges` поглощает resize (`AndroidManifest.xml:47-70`).
- **Space.** `AppSystemActivity` с `VRFeature` + `ComposeFeature`
  (`ImmersiveActivity.kt:130-131`), одна `PanelRegistration`: 1024×640 dp при
  `layoutDpi=288` → текстура 1843×1152 px на квад 1.0×0.625 м (`:237-250`);
  `LOCAL_FLOOR`, `enablePassthrough(true)`, панель ставится один раз в 1.3 м по взгляду
  (`:162-178`, `:279-292`), `Grabbable`, без billboard и без re-place на recenter.
  1 dp ≈ 0.98 мм → 72 dp ≈ 3.1°, 32 dp ≈ 1.4°.
- **Переход Панель ↔ Space.** Данные общие через `Graph`; **UI-состояние не переносится** —
  у каждого хоста свой `NavController` и свои ViewModel'и, Space всегда открывается на Today.
  Выход из Space: Home-intent с `PendingIntent` на панель + `finish()` (`:181-198`).
