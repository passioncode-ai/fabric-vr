## What the product is

A notes application for a Meta Quest 3 that sits **beside** a streamed desktop rather than replacing
it. You press one button, speak, press again; whisper.cpp transcribes on the headset (or a cloud
endpoint does); the text becomes a note and lands on the system clipboard so you can paste it into
whatever you were actually working in. Every note is mirrored to Markdown in a vault. There is also
a search screen. **There is no assistant**: `DEC-0020` cut it from v1 and commit `4f9cbf6`
deleted the screen, its view model and the route — `:feature-assistant` is still in the tree with
its tests and nothing in the APK links it. This sentence claimed otherwise until the group
verification of steps 4–5, in the one document this project declares true.

It runs in two hosts from one Compose tree: a flat panel in the Horizon OS shell
(`PanelActivity`) and an immersive Space (`ImmersiveActivity`, Meta Spatial SDK). It is installed
on two Quest 3 headsets — the operator's and a second person's.

## The rules for finishing a task

1. Meet every item in the spec's **Definition of Done**.
2. The tests the spec names exist, **and you watched each one fail before the fix**. A test that was
   green before you changed anything is testing something else — this project has shipped two of
   those and both were found by planting the defect deliberately.
3. `bash scripts/check-all.sh` green — one script, so "green locally" and "green in CI" cannot
   mean two different sets of checks. Add `--with-lint` before pushing anything release-shaped.
   **And read the CI verdict afterwards**: `gh run list --limit 1`. Five commits in a row claimed a
   lint gate that was not running.
4. **A gate you add carries a canary and a planted red.** Three of this project's gates have
   printed a clean green while reading nothing. The pattern to copy is
   `scripts/check-secrets.sh`'s in-memory canary.
5. The commit message says what changed **and what it traded away**.
6. Move the task's board row in `docs/evidence/backlog.md` in the same commit.
7. A user-facing change updates `docs/ux/scenarios.md` in the same change. A decision that is hard
   to reverse gets a `DEC-` row.

## Building it

```bash
git submodule update --init --recursive
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :app:assembleDebug
```

Android SDK 35, NDK 27.2.12479018, CMake 3.22.1. The speech model is downloaded by the app, not
committed. `scripts/push-model-for-tests.sh` puts it where the instrumented tests read it.

`main` carries the project as of 2026-09-20 (T-004), and a clone of it was built from scratch to
prove it. The JDK bound is enforced by `settings.gradle.kts` before any module is configured, so a
machine with the wrong `java` is told which JDK and how to get it rather than failing on
"Unsupported class file major version" six modules later.

**Work continues on `feat/v1-notes-core`**, and `main` is fast-forwarded to it at each verification
checkpoint — never the other way, and never with a merge commit. If the two have diverged, that is
a defect, not a state to resolve creatively.
