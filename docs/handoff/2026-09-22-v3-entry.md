## What the product is

**Fabric's remote surface** (`DEC-0100`, the operator, 2026-09-29): the Quest first, then an
Android phone from the same code. The Mac holds the Estate: journal, policy, grants, Agents.
These surfaces reach it only through the northbound MCP, carried by one relay. The modules are
Attention, Projects, Agents and runs, Capture, Knowledge and Role workspaces. The shared
clipboard stays a later layer. It never renders a desktop; it sits **beside** one. `DEC-0064`'s
notes-first framing is superseded; its notes are now the Capture module.

What exists today is only Capture, with no connection to Fabric. It is the notes core and the
dictation: press once, speak, press again. whisper.cpp transcribes on the headset (or a cloud
endpoint, or your own whisper-server), and the text becomes a note and lands on the clipboard.
Every note is mirrored to Markdown in a vault, and the vault can be exported **and imported
back** (`REQ-054`). Two hosts run one Compose tree: a 2D panel in the Horizon OS shell and an
immersive Space.

## The rules for finishing a task

1. Meet the spec's Definition of Done, and **watch every test fail before the fix** (`SI-06`).
2. `bash scripts/check-all.sh` green — and **the push is chained to its exit code, never to a
   grep** (`SI-03`). Run it in your own shell and let it finish: its last line leaves a receipt
   naming the tree it passed on, and `.githooks/pre-push` refuses any tree the receipt does not
   name. Arm it once per clone: `git config core.hooksPath .githooks`. **The hook does not run
   the gates** — it did, and every push then died on `SIGPIPE` after they passed, because git
   holds its connection to the remote open across the hook and GitHub closes an idle session
   first.
3. A gate you add carries a canary and a planted red in `scripts/selftest.sh`. Where a plant is
   impossible, say so in the file — `B-193` is the one case that could not be planted honestly.
4. **A subagent's report is not evidence** (`SI-11`): re-plant the defect in the integrated tree
   before believing a merge. Three defects this run were invisible from inside the branches that
   caused them.
5. Move the board row in the same commit; a user-facing change updates `docs/ux/scenarios.md`; a
   hard-to-reverse call gets a `DEC-`.
6. The commit message says what changed **and what it traded away**.
