## 1. How infrastructure layers won as hardware/OS commoditized

- **Keyboards**: Gboard/SwiftKey personal dictionary + style sync; users lose years of vocabulary when switching (Reddit, 2025-01); FUTO wins on local-only [clevertype.co, 2026-02].
- **Voice dictation**: **Wispr Flow** (personal dictionary, per-app style) raised **$280M Series B at $2B** [wisprflow.ai/post/series-b]; Free (2,000 words/wk) → Pro $15/mo ($12 annual) → Teams $10–12 → Growth $18–26 → Enterprise [wisprflow.ai/pricing, 2026-09]. Closest structural analog to Fabric VR dictation.
- **Meeting notes**: Granola $14/user/mo Business, free 25 lifetime meetings / 30-day history [granola.ai/blog, 2026-02/04]; transcripts retained indefinitely absent policy [tldv.io, 2026-08]. Otter $8.33–17, Fireflies ~$10–18, Fathom $16–20 (best free tier). Asset = searchable cross-meeting memory.
- **Personal AI memory — cautionary**: **Meta acquired Limitless (ex-Rewind) 2025-12-05**, stopped Pendant sales, shut Rewind Mac app 2025-12-19, discontinued EU/UK/Brazil/China service [hedy.ai; FT, 2025-12]. Survivors: Screenpipe (local-first), Microsoft Recall (opt-in, on-device, Copilot+ PC). **Meta is the buyer of this thesis.**
- **Memory portability counter-force**: OpenAI "Dreaming V3" background memory synthesis 2026-06-04; Claude memory + "import memory from other providers" (2026-03). Data lock alone weakens → durability from workflow habit.
- **AR glasses**: Ray-Ban Meta sales tripled in 2025 (EssilorLuxottica, 2026-02-11) [cnbc.com]; Meta building "remember faces / where you put keys" memory into Ray-Ban Display [nypost.com, 2026-05-11].

## 2. Data-moat frameworks (six arguments)

1. Casado & Lauten, *The Empty Promise of Data Moats* (a16z, 2019-05-09): data-scale effects have fast-diminishing returns.
2. V7 Labs, *Are Data Moats Dead in the Age of AI?* (2025-12-15): defensible only if proprietary, outcome-relevant, structured and in a continuous learning loop — else "a storage unit".
3. *The memory is the moat* (fabric.so, 2026-09): accumulated context compounds daily and can't be bought; structure as a **user-owned encrypted library with open export (MCP)**.
4. *Context is the moat, model is a commodity* (Medium 2025-11; Glean 2026-08).
5. *The harness is the moat* (2026-04..08) — contested; orchestration itself commoditizing.
6. 7 Powers for AI + System of Record vs System of Engagement (Tidemark, Vantage Point, 2026): switching costs and cornered resources most durable; own the daily point of engagement.

**Implication**: (a) asset must be structured and operationalized into daily workflow; (b) position as system-of-engagement (voice/agent surface touched hourly); (c) switching cost from habit + integration depth, not data hostage-taking.

## 5. Privacy / regulatory

- **EU AI Act**: Art. 5 prohibitions (incl. emotion inference from voice/face in the workplace) since early 2025; general applicability **2026-08-02** [digital-strategy.ec.europa.eu]. No "stress from voice" features in the EU.
- **GDPR**: voice used for identification = biometric special-category (Art. 9) → explicit consent; AEPD guidance on AI transcription (2026-04).
- **US recording law**: ~11 all-party-consent states (lists vary); Mayer Brown (2026-06) flags always-on AI notetakers as a distinct wiretap-liability category.
- Horizon Store: App Privacy labels, privacy policy naming data categories; API access suspended after 90 days unused.
- **SOC 2 Type II table stakes**; HIPAA/BAA differentiator (Otter yes, Granola no).
- Local-first live: Wispr AES-256 + hardware-backed tokens; Screenpipe, Recall on-device; BYOK standard enterprise ask.

## Packaging options

**A — "Second Brain for Meetings + Voice"**: asset = relationship graph + meeting/decision memory; loop = every VR-joined call and dictated note enriches it; freemium → $15–20 Pro → $25–35 team; risk = most crowded lane (Granola/Otter/Fireflies/Fathom), differentiation thin if a desktop competitor adds voice.

**B — "The Agent You Talk To" (harness-is-the-moat)**: asset = tuned control loop that learned the user's tools, shortcuts, permissions, corrections on *their* machine; loop = every command and correction refines the execution policy; one $20–30/mo subscription covering free Quest app + Mac/PC agent (Immersed model); risk = harness commoditizing (OpenClaw etc.), needs continuous UX/integration investment.

**C — "Work Ops Utility, Privacy-First"**: asset = encrypted, user-owned, exportable/BYOK context store; loop = local-first capture grows usefulness without GDPR/consent/AI-Act exposure → wedge into regulated industries; $30–40/user/mo + Enterprise/BYOK, B2B; risk = on-device model quality, slow enterprise cycles vs small installed base.
